# Spec — Voter rework for the 2026-08-18 FL primary

Date: 2026-08-06. Horizon: the FL primary on 2026-08-18 (Decision 1).
Inputs: `DECISIONS-2026-08-06.md` (13 decisions), `TODOS.md` (work items + 7 technical constraints), `DATA-SOURCES-2026-08-06.md` (source stack), `DATA-AUDIT-2026-08-06.md` (evidence).
Process: this spec feeds `TICKETS-2026-08-06.md`. Implementation follows `../AGENT-ORCHESTRATION.md`.

## Goal

Ship a rebuilt voter product before the primary. The product must show only verified ballot facts, on the 2026 congressional map, with honest UI states, working engagement writes, and a design system rooted in code.

## Non-goals (this run)

- No challenger stance authoring. That is a separate follow-up run (Tommy's call, 2026-08-06). The adversarial gate in `../AGENT-ORCHESTRATION.md` still applies when it runs.
- No Governor surface (Decision 8).
- No general election, no municipal races.
- No Ballotpedia paid API integration. The sales quote is pursued separately.
- No merge to `main`. All work stays on a branch until Tommy's explicit go (Decision 13).

## Standing constraints

Every ticket inherits the 13 decisions in `DECISIONS-2026-08-06.md` and the 7 "Decided constraints" in `TODOS.md`. Do not re-litigate them. The most load-bearing ones for implementation:

- Errors surface; reads never fake success. The one exception is the `/api/match` heuristic fallback, which the UI must label "estimated match".
- One session identity: the `voter_session` httpOnly cookie. Delete the localStorage path.
- Design source of truth is code: one token module feeds Tailwind, components, and `/api/og`.
- Writes flow handler → application module → data adapter. Exactly one anon adapter and one service-role adapter.
- Typed data at one boundary; no raw snake_case rows in components.
- Match results travel by URL/server state.
- All ID joins; name matching is eliminated everywhere (Decision 6).

`/candidate/{id}/totals?cycle=2026` (Senate: `election_full=true&election_year=2026`). Never omit `cycle`; never fall back to older cycles — show "no 2026 filings yet". Render `coverage_end_date` next to every figure. Re-pull after Aug 8 for pre-primary filings (Decision 7).
